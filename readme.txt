**RustDM** — это сверхбыстрый, современный и умный менеджер загрузок с открытым исходным кодом (альтернатива Free Download Manager), написанный с нуля на **Rust** (`eframe` / `egui`). 

Главное отличие **RustDM** — прямое управление железом процессора (привязка потоков к самым быстрым P-ядрам), умная адаптация под игры и нагрузку ПК, маршрутизация через узлы **Cloudflare Edge** и встроенный модульный движок **HyperShield GPU**.

---

## 🔥 Ключевые возможности

### 🧠 1. Движок 50/50 Dual P-Core Pinning
* При старте загрузки сканирует топологию процессора в реальном времени.
* Находит **2 самых высокочастотных и наименее нагруженных P-ядра (Performance Cores)**.
* Делит файл ровно **50/50**: первая половина качается на первом P-ядре, вторая — параллельно на втором P-ядре с жёсткой аппаратной привязкой (`core_affinity`).

### 🎮 2. Режим «Авто (Под CPU)» и «Режим Улитки»
* **Авто-приоритет (Под CPU):** Фоновый радар следит за общей нагрузкой процессора:
  * **CPU < 35%** — `Турбо-Буст` (максимальная скорость).
  * **CPU 35%–75%** — `Баланс` (оптимальный режим).
  * **CPU ≥ 75%** — `Игровой / Тихий режим` (автоматически снижает обороты, чтобы не вызывать фризов и просадок FPS в играх).
* **♦ Режим Улитки (Snail Mode):** В один клик отдаёт весь интернет-канал главной активной загрузке, переводя остальные закачки в фоновый тихий режим.

### 🌐 3. Глубокий сетевой инспектор и защита от пустышек (Anti-HTML Trap)
* Перед скачиванием проверяет **реальную доступность самого файла**, а не просто пинг домена.
* Распознаёт ошибки `404 Not Found`, `403 Forbidden` и блокирует сайты-ловушки, которые вместо запрашиваемого файла (`.txt`, `.zip`, `.exe`, `.iso`) пытаются подсунуть HTML-страницу.
* Поддержка маршрутизации через узлы **Cloudflare Edge** (`Авто-выбор`, `Франкфурт`, `Амстердам`, `Варшава`, `Хельсинки`, `Напрямую`) с бесшумной автокалибровкой при запуске.

### 🛡 4. Внутренняя библиотека `HyperShield GPU`
Собственный модульный конвейер безопасности (`src/hyper_shield`):
* **Вариант А (8-поточная матричная сверка хеша):** Параллельная проверка целостности склеенных половин 50/50.
* **Вариант Б (Лёгкий сигнатурный и эвристический антивирус):** Мгновенная проверка заголовков `MZ/PE`, скрытых скриптов и опасных сигнатур без нагрузки на систему. Выводит вердикт прямо на карточку файла (`✔ ЧИСТО [HASH]` или `! ОПАСНО: ВИРУС !`).

### 📁 5. Полная интеграция с Проводником Windows
* Нативный выбор папок через диалоговое окно Windows Explorer.
* Кнопка открытия папки с автоматической подсветкой скачанного файла (`/select,`).
* **Дисковый радар:** Если удалить скачанный файл на ПК через Проводник, он автоматически исчезнет из списка программы. При удалении незаконченной загрузки программа сама подчищает временные `.rustdm.part` файлы.

## 🏗 Модульная архитектура проекта (`src/`)

* `main.rs` — Графическое ядро приложения, окна, фильтрация и координация состояний.
* `ui_theme.rs` — Неоновая дизайн-система **Flux Dark**, кастомные векторные виджеты и двухслойные аватарки типов файлов (`ISO`, `TOR`, `ZIP`, `EXE`, `VID`, `FILE`).
* `cpu_manager.rs` — Анализатор частот процессора и привязка потоков к P-ядрам.
* `network_cf.rs` — Модуль маршрутизации и фоновой калибровки узлов Cloudflare.
* `download_engine.rs` — Многопоточный HTTP/HTTPS загрузчик 50/50 и инспектор ссылок.
* `fs_watcher.rs` — Интеграция с ОС Windows, управление `.rustdm.part` и мониторинг диска.
* `hyper_shield/mod.rs` — Внутренняя библиотека GPU-верификации хеша и антивирусного анализа.

## 🚀 Сборка и запуск из исходников

Убедитесь, что у вас установлен [Rust (cargo)](https://rustup.rs/).

```powershell
# Клонирование репозитория
git clone https://github.com/14goga1000-create/Rust-FD.git
cd Rust-FD

# Запуск в режиме разработки
cargo run

# Сборка автономного релизного .exe (без фоновой консоли)
cargo build --release
